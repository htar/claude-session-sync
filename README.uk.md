# Session Sync for Claude Code

[English](README.md) · **Українська** · [Español](README.es.md) · [简体中文](README.zh-CN.md)

> Unofficial community extension. Not affiliated with or endorsed by Anthropic. «Claude» and «Claude Code» are trademarks of Anthropic.

Продовжуйте сесію Claude Code на іншому пристрої. Розширення переносить історію сесій між вашими комп'ютерами
без власного сервера: дані ходять через те, чим ви вже користуєтесь.

## Як користуватися

Команди відкриваються через палітру: **Cmd+Shift+P** (Windows і Linux: Ctrl+Shift+P), далі слово «Claude Sync».

### Пристрій, на якому працювали

1. Відкрийте проєкт у VS Code.
2. Виконайте **Claude Sync: Push sessions**.
3. Перший раз виберіть спосіб переносу (див. нижче). Решту розширення зробить саме.

### Пристрій, на якому продовжуєте

1. Встановіть розширення й відкрийте **той самий проєкт** (з тим самим git remote).
2. Виконайте **Claude Sync: Pull sessions** і виберіть той самий спосіб.
3. Виберіть, **з якого пристрою** імпортувати (пропускається, якщо експортував лише один інший пристрій).
4. З'явиться список сесій цього пристрою: назва, дата, розмір і статус. Відмітьте потрібні або натисніть «Select all».
5. Виконайте **Claude Sync: Resume a session**, виберіть сесію, і відкриється термінал із `claude --resume`.

### Правила

- **Push перед тим, як піти з пристрою, і Pull перед тим, як почати на іншому.**
- Не продовжуйте одну сесію на двох пристроях одночасно: розширення покаже конфлікт і нічого не перезапише.
- Перенесена сесія може не відразу з'явитися у списку сесій Claude Code. Перезавантажте вікно (**Developer: Reload Window**) або скористайтеся **Claude Sync: Resume a session**: вона відкриває сесію напряму.
- Хмара доставляє файли не миттєво: якщо Pull нічого не знайшов, зачекайте хвилину.
- Кожен пристрій експортує у свій каталог (названий за пристроєм, див. `claudeSessionSync.deviceName`), тож пристрої не перезаписують один одного, а джерело ви вибираєте самі.
- Видалити експортоване пристроєм: **Claude Sync: Delete exported sessions** (просить підтвердження; ваші власні сесії на пристроях не чіпаються).
- Натисніть **Claude Sync** у рядку стану (або виконайте **Claude Sync: Manage connection**), щоб змінити спосіб або відключитися. Якщо сховище недоступне чи ви не увійшли в обліковий запис, розширення запропонує увійти знову або вибрати сховище ще раз (на новому пристрої це робиться один раз; Dropbox знаходиться навіть на нестандартному диску).
- Змінити спосіб переносу: **Claude Sync: Choose sync method**. Відключити хмару: **Claude Sync: Disconnect storage** (нічого не видаляється зі сховища чи з пристрою).

## Способи переносу

| Спосіб                      | Що треба                                                                  | Що відбувається                                                                                                                                    |
| --------------------------- | ------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------- |
| **GitHub**                  | Акаунт GitHub                                                             | Вхід в один клік через VS Code, приватний репозиторій `claude-sessions` створюється сам. Публічний такий відхиляється.                             |
| **Dropbox (напряму)**       | Обліковий запис Dropbox                                                   | Вхід одним кліком у браузері, застосунок Dropbox на комп'ютері не потрібен. Файли лежать у `Apps/Session Sync for Claude Code` у вашому Dropbox.   |
| **OneDrive (напряму)**      | Обліковий запис Microsoft                                                 | Вхід одним кліком у браузері, застосунок OneDrive на комп'ютері не потрібен. Файли лежать у `Apps/Session Sync for Claude Code` у вашому OneDrive. |
| **Хмарне сховище**          | iCloud Drive, Google Drive, MEGA, pCloud, Box, Proton Drive або Nextcloud | Ви вибираєте сховище зі списку, у його корені створюється папка «Claude Sessions», а далі файли доставляє сам клієнт хмари.                        |
| **Власний git-репозиторій** | Приватний репозиторій і доступ до нього (SSH або credential helper)       | Вкажіть його адресу в `claudeSessionSync.repoUrl`.                                                                                                 |

## Налаштування

Усі налаштування діють на рівні машини: задавайте їх у User settings.

| Налаштування                          | За замовчуванням                                           | Що робить                                                                                                                        |
| ------------------------------------- | ---------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------- |
| `claudeSessionSync.mode`              | порожньо                                                   | `github`, `dropbox`, `onedrive`, `folder` (папка хмарного сховища) або `git`. Порожньо = спитати при першому використанні.       |
| `claudeSessionSync.syncFolder`        | порожньо                                                   | Спосіб «папка хмарного сховища»: папка із сесіями. Заповнюється, коли ви вибираєте сховище.                                      |
| `claudeSessionSync.claudeDir`         | порожньо                                                   | Папка Claude Code, якщо це не `~/.claude` (інакше `CLAUDE_CONFIG_DIR`). Передається і в «Resume a session».                      |
| `claudeSessionSync.deviceName`        | ім'я комп'ютера, запам'ятовується при першому використанні | Назва цього пристрою у сховищі: її вибирають інші пристрої під час імпорту.                                                      |
| `claudeSessionSync.projectKey`        | порожньо                                                   | Однакове значення на всіх пристроях для проєкту без git remote (або з різними remote). Порожньо = git remote, інакше назва теки. |
| `claudeSessionSync.repoUrl`           | порожньо                                                   | Адреса приватного репозиторію для способу «власний git».                                                                         |
| `claudeSessionSync.maxFileSizeMB`     | `90`                                                       | Сесії більші за це не пушаться (і про них попереджають).                                                                         |
| `claudeSessionSync.maxSessionAgeDays` | `30`                                                       | Пушаться лише сесії, змінені за останні N днів. `0` = без обмеження.                                                             |
| `claudeSessionSync.scanSecrets`       | `true`                                                     | Перевіряти сесії перед Push на API-ключі, токени й приватні ключі та пропонувати їх не надсилати.                                |

## Якщо щось пішло не так

| Що ви бачите                                                                                  | Що це означає і що робити                                                                                               |
| --------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------- |
| «cannot reach the storage»                                                                    | Немає інтернету або сервіс недоступний. Розширення вже повторило спробу; натисніть «Try again», коли з'явиться зв'язок. |
| «the storage is full»                                                                         | Звільніть місце в Dropbox/OneDrive/GitHub або виберіть інший спосіб.                                                    |
| «did not accept the sign-in»                                                                  | Доступ закінчився або відкликаний. Натисніть «Sign in again».                                                           |
| «Another computer already pushes as …»                                                        | У двох комп'ютерів однакове ім'я пристрою. Перейменуйте цей (пропонується) або підтвердіть, що це той самий комп'ютер.  |
| Pull нічого не знаходить                                                                      | Інший пристрій ще не робив Push, або використовує інший спосіб чи інший ключ проєкту (див. `projectKey`).               |
| Вхід у Dropbox/OneDrive не завершується у віддаленому вікні (SSH, WSL, контейнер, Codespaces) | Браузер не дістається до VS Code. Використайте GitHub або власний git-репозиторій.                                      |

**Claude Sync: Disconnect storage** також видаляє копію, яку розширення тримає на цьому комп'ютері для синхронізації; ваші власні сесії Claude Code не чіпаються.

## Безпека

- **Шифрування** (за бажанням): **Claude Sync: Turn on encryption** шифрує сесії у сховищі парольною фразою
  (AES-256-GCM, ключ через scrypt). Сховище бачить лише зашифровані файли; кожен інший пристрій один раз попросить
  фразу. Втрачену фразу відновити неможливо. Пристрої зі старішою версією розширення зашифрованих сесій не побачать.
- Перед кожним Push сесії, що мають піти, перевіряються на API-ключі, токени й приватні ключі (AWS, GitHub,
  Anthropic, OpenAI, Slack, Stripe, Google, npm). Якщо щось знайдено, ви побачите, які це сесії, і зможете їх не
  надсилати. Вимикається через `claudeSessionSync.scanSecrets`.
- Сесії містять ваш код, вивід команд і **можливо секрети**. Переносьте їх лише у приватне сховище: приватний
  репозиторій або вашу власну хмару. Перед першим Push розширення про це попереджає.
- Спосіб GitHub просить дозвіл `repo` (вужчого для приватних репозиторіїв GitHub не має). Токен лишається у VS Code,
  код розширення відкритий.
- Якщо в iCloud увімкнено «Optimize Mac Storage», частина сесій може бути не завантажена на цей Mac. Розширення
  покаже скільки, і підкаже, що зробити.

## Обмеження

- Синхронізуються сесії поточного проєкту (першої відкритої папки), а не всі одразу.
- Синхронізація ручна, фонового режиму немає.
